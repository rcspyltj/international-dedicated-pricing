## 先给量级结论：国际专线费用差在哪

同样是“国际专线”四个字，市面上的报价能差出三个数量级，原因是交付的东西完全不同：

- **运营商级 IPLC/IEPL/MPLS 专线**：按独享带宽计费，公开资料整理的行情大致是香港方向约 300 元/Mbps/月，美国、德国方向约 300～400 元/Mbps/月，中东非更高。一条 5M 独享专线一年下来就是一万八上下，再加上端口费、本地电路费和 SLA 服务费，年费数万到数十万很正常。有行业文章给出的中美专线年费区间甚至到百万元级别，主要面向金融机构和大型跨国企业。
- **SD-WAN/软专线方案**：相对运营商便宜三到六成，按公开资料，办公账号版约 690 元/年，独享 IP 套餐 1500 元/年起，美区 5M 独享专线约 10000 元/年。
- **专线 VPS**：把服务器和跨境线路打包成月付产品，共享带宽档月付一百多到四百多就能起步，独享带宽档从每月几百元起。

三者不是替代关系。运营商专线给你的是带 SLA 的企业组网能力，专线 VPS 给你的是一台跑在跨境线路上的服务器，SD-WAN 介于两者之间。下面重点展开第三类，因为它是中小跨境团队最容易上手的方案。

## 共享和独享：差价背后的账怎么算

Mkcloud 官方知识库专门用沪港线路举过例子，这个例子很能说明问题：

- 沪港共享入门：1 核 2G、200Mbps 峰值、1024GB 月流量，月付 288 元
- 沪港独享入门：2 核 4G、5Mbps 独享、不限流量，官方选型文档列为 388 元/月起（商店页现价略有浮动，下单前以页面为准）

共享的 200Mbps 是峰值，不保证持续跑满；独享的 5Mbps 是持续占有的速率。短时间上传素材、日常后台操作，共享档的流量额度更实用；直播推流、长时间大批量传输，独享档的持续速率才有意义。计量型套餐按上行加下行双向统计流量，超量会暂停，可以买流量重置或者补差价升级。

还有个容易踩的坑：长周期不一定便宜。官方知识库确认过，沪港共享入门款季付 864 元、年付 3456 元，折算回每月还是 288 元，和月付一个价。别默认年付就打折，下单前自己除一下。

## 常见问题

**国际专线一个月到底多少钱？**
分层看：SD-WAN 办公账号版折算下来几十块一个月；专线 VPS 共享档 158～428 元/月起步；5M 独享带宽几百元/月；运营商级独享专线按 300 元/Mbps/月上下的行情算，5M 就是一年近两万。

**几百块的“专线”和运营商几万的专线是一回事吗？**
不是同一种产品。前者交付的是一台带跨境线路的服务器，后者交付的是带带宽保证和 SLA 的企业电路。拿两者的价格直接比没有意义，拿前者替代企业组网也不合适。

**开通后多久能用？**
官方口径约 1 分钟自动开通，指系统可用。业务软件、环境和数据要自己装。

**超了流量怎么办？**
计量型套餐超量会暂停，可以自助购买流量重置，或提交工单补差价升级套餐。

**能退吗？**
仅质量问题退款，需要提交具体的延迟、速度数据，由商家审核；开通后不能换地域。这条下单前想清楚。
